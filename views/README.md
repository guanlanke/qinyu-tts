# views/ · 管理面板

AstrBot 插件默认只有配置表单。这里放的是一个**独立的管理面板**——比配置页更直观，日常操作不用翻几十个参数。

## 目录

| 文件 | 行数 | 职责 |
|---|---|---|
| `singing/index.html` | 145 | 页面结构：三层信息架构 |
| `singing/app.js` | 414 | 前端逻辑：调插件注册的 Web API，处理交互与状态 |
| `singing/style.css` | 618 | 样式与动效 |

纯静态，无构建步骤、无框架依赖——一个 HTML + 一个 JS + 一个 CSS，改完刷新就生效。

## 页面结构

按"日常用得到 → 排障才用"排成三层：

**第一层 · 唱多久**

五个按钮：短 20 秒 / 中 40 秒 / 长 60 秒 / 很长 90 秒 / 自定义。点一下立即生效，不用点保存。

**第二层 · 私聊与群聊**

一句话状态（一致 / 有 N 项不同）+ 仅在异常时才出现的绑定表 + 一键统一按钮。正常时这块只有一个"一致"提示，不占视线。

**第三层 · 诊断 / 高级设置**

两个折叠区，默认不展开。秒数、上限、补足、语速这些收在这里。

## 后端接口

面板不直接读写配置，所有操作走插件在 `main.py` 注册的 Web API：

```
GET  /astrbot_plugin_qinyu/status   读当前状态（音色、时长、绑定、诊断）
POST /astrbot_plugin_qinyu/apply    应用改动（时长预设、统一、绑定）
```

注册代码在 `main.py` 的 `_register_web_apis()`。如果 AstrBot 版本不提供 `register_web_api`，注册会失败但**不影响插件主体**——只是面板按钮不可用，聊天指令照常。

## 样式约定

用 CSS 变量统一控制主题，跟 AstrBot 的深浅色自动适配：

```css
:root {
  --bg-card: ...;
  --text-primary: ...;
  --accent: ...;
}
```

动画都很短（120ms 淡入、150ms 过渡），并且整段包在 `@media (prefers-reduced-motion: reduce)` 里——系统开了"减少动画"就全部关闭。

## 改面板要注意

**按钮改的不是一个值，是一组值**。比如点"中"（40 秒），实际会同时设置目标 40 秒、上限 60 秒，并把 `singing_target_seconds_private` / `_group` 这类会话级覆盖清回 0。否则会出现"点了中，群里还是 120 秒"这种第二次困惑。

**手动改秒数要清掉预设高亮**。改完不取消 preset 状态，按钮高亮会和实际值打架。
