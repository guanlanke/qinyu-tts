## 它是什么

一个 AstrBot 语音插件。把机器人的文字回复变成语音——**不只是念出来，而是带着语气说出来；不只是唱出声，而是唱得能听。**

支持 10 种 TTS 引擎，其中 MiMo V2.5 支持完整的唱歌模式。说话和唱歌共用一套配置：引擎、音色、风格、时长，一处设定，两处生效。

---

## 为什么值得装

大多数 TTS 插件能"出声"，但声音是平的。这个插件花力气解决的是出声之后的问题：

**说话像个真人，不是播报机**
读取当前会话人设，提炼出轻快、顽皮、温柔这类特征，转成语气指导。活泼的人设说话就轻快，慵懒的就沉稳——不用手动调。还会实测你的语速，把「多少字算多久」校准到真实水平。

**唱歌不会「越唱越崩」**
语音模型在长句后段容易失稳。这里做了三件事：按整句切分绝不半句、指令要求「连成一首歌从头唱到尾、不要一句一停」、时长预设按需收口。不是让它唱得长，是让它唱得完整。

**几个容易踩的坑都填了**

| 坑 | 处理 |
|---|---|
| 歌词残缺 → 跑调 | 只按整句边界切，宁可短也不断 |
| 中途变成念白 | `user` 指令 + `assistant` 标签双层隔离，物理上串不过去 |
| （换气）（气声）被当垃圾清掉 | 这些是演唱控制信号，保留；只剔叹气、哽咽这类表演标签 |
| 风格词被念出来 | 风格描述走 `user` 自然语言通道，永不进入要唱的正文 |
| 唱歌音色跟着朗读走 | 两组音色独立解析，互不覆盖 |
| 私聊和群聊像两个人 | 统一模式 + 一键拉平 + 差异对比 |

**风格能叠，不是单选**
整体语调、音色质感、人设腔调、方言、角色扮演，五个维度各自独立。比如"温柔的语调 + 甜美的音色 + 夹子音的腔调"是三层叠加。改一次，说话和唱歌同时生效。

**不用记参数**
可视化管理面板：点一个词选时长、一键统一私聊群聊、`/tts_doctor` 自检、`/tts_diff` 对比差异。

## 快速开始

```bash
# 1. 装插件，进配置页添加引擎，填 API Key
# 2. 设两个音色：朗读音色 + 唱歌音色（可以不同）
# 3. 直接聊 —— 说话自动有语音
```

让它唱歌：

```
/tts_sing 窗外的雨下不停，我的心也跟着乱了节奏
```

或者直接说「唱首雨爱」。

> 🎯 想稳定唱满一段，用 `/tts_sing` 贴完整歌词——给多少唱多少，不经 LLM 记忆。

## 它做了什么

### 说话

- **语气承接人设**：读会话人设，提炼特征转成自然语言语气指导
- **语速自动校准**：实测真实语速，长回复不被硬切
- **双层隔离**：朗读与唱歌两条独立链路，互不污染
- **全局风格**：五维风格朗读唱歌共用

### 唱歌

四条链路任选，覆盖不同场景：

| 方式 | 用法 | 特点 |
|---|---|---|
| 直给歌词 | `/tts_sing <歌词>` | **最可靠**，给多少唱多少，不经 LLM |
| 自然语言 | 「唱首雨爱」 | 顺手，但依赖 LLM 对歌词的记忆 |
| 关键词触发 | 配置关键词表 | 兜底，LLM 没打标签时接管 |
| 整段原样 | 保持原文送出 | 不做任何清洗，一个字符不动 |

### 风格

| 维度 | 可选值 |
|---|---|
| 整体语调 | 温柔 / 高冷 / 活泼 / 严肃 / 慵懒 / 俏皮 / 深沉 / 干练 / 凌厉 |
| 音色质感 | 磁性 / 醇厚 / 清亮 / 空灵 / 稚嫩 / 苍老 / **甜美** / 沙哑 / 醇雅 |
| 人设腔调 | **夹子音** / 御姐音 / 正太音 / 大叔音 / 台湾腔 |
| 方言 | 东北话 / 四川话 / 河南话 / 粤语 |
| 角色扮演 | 自由输入，不限选项 |

### 统一

- **统一模式**（默认开）：读配置时直接忽略会话级覆盖，私聊群聊结构上不可能分叉
- `/tts_unify`：一键拉平引擎、音色、时长、上限、禁唱时段
- `/tts_diff`：差异逐项摊开，哪一项不同、差在哪、怎么改

### 面板

- **唱多久**：一屏五个按钮（短 20 秒 / 中 40 秒 / 长 60 秒 / 很长 90 秒 / 自定义）
- **私聊与群聊**：一句话状态 + 异常时才出现的绑定表 + 一键统一
- **诊断 / 高级设置**：两个折叠区，日常不用打开

## 安装

### 方式一 · 插件市场

AstrBot 管理面板 → 插件市场 → 填本仓库地址安装。

### 方式二 · 上传 zip

把插件目录打包成 zip，用面板「安装插件 → 上传文件」上传。

> ⚠️ zip 结构有硬要求：内部必须是单层目录 `astrbot_plugin_qinyu/`，目录名与 `metadata.yaml` 的 `name` 完全一致；条目分隔符必须是正斜杠 `/`。
>
> Windows 右键「压缩」和 PowerShell `Compress-Archive` 会写成反斜杠，Linux 容器里解压后只会得到一个文件名含反斜杠的单文件，安装报 `FileNotFoundError`。

仓库自带打包脚本，会按 AstrBot 的解压逻辑做一次真实安装验证：

```bash
python tools/build_plugin_zip.py
```

## 配置与使用

### 第一步 · 配引擎

1. 进入插件配置页
2. 点「TTS 引擎配置列表」→ 添加引擎（按 `[提供商]` 分组）
3. 填 API Key、API Base、模型名
4. 确认机器人已开启 AstrBot 的 TTS 功能

> 💡 列表第一个是默认引擎，也可用「当前生效的引擎实例名称」指定。

### 第二步 · 配声音

两组音色，**互相独立**：

- **朗读音色**：日常说话用
- **唱歌音色**：只影响唱歌

唱歌觉得"声音薄"，换 **茉莉** 或 **白桦**（中文厚声）。英文音色唱中文会带外国口音，插件会自动换成中文音色。

### 第三步 · 配风格（可选）

任何组合都行，全部留「不设置」就是模型原生音色：

```
整体语调 = 温柔
音色质感 = 甜美
人设腔调 = 夹子音
```

### 第四步 · 设时长

面板上点一个词，或在聊天里说：

```
/tts_set 时长 中
```

| 预设 | 目标 | 上限 |
|---|---|---|
| 短 | 20 秒 | 30 秒 |
| 中 | 40 秒 | 60 秒 |
| 长 | 60 秒 | 90 秒 |
| 很长 | 90 秒 | 135 秒 |

### 第五步 · 用起来

**说话**：什么都不用做，机器人回复时自动转语音。

**唱歌**：`/tts_sing <歌词>`，或直接说「唱首雨爱」。

### 指令速查

| 指令 | 作用 |
|---|---|
| `/tts_sing <歌词>` | 指定歌词演唱 |
| `/tts_set 时长 中` | 改唱歌时长 |
| `/tts_panel` | 打开管理面板 |
| `/tts_status` | 看当前状态 |
| `/tts_unify` | 统一私聊与群聊 |
| `/tts_diff` | 对比当前会话与全局差异 |
| `/tts_doctor` | 自检：哪个功能不可用、为什么 |
| `/tts_reload` | 清空引擎缓存，让配置立即生效 |
| `/tts_limit` | TTS 字数上限（看状态 / 设置 / 关闭） |
| `/tts_on` / `/tts_off` | 开关 TTS |

管理指令默认仅管理员可用；平台识别不出管理员时，在配置的 `admin_user_ids` 填用户 ID。

### 遇到问题先做两件事

1. **`/tts_doctor`** —— 告诉你缺什么、为什么、下一步做什么
2. **`/tts_diff`** —— 私聊和群聊各发一次，差异逐项摊开

```
连接       实例名 / API Key / Base URL / 模型
音色输出   朗读音色 / 唱歌音色 / 格式 / 超时

```

> 日常操作在 `/tts_panel` 点按钮即可，不必进配置页。

## 关于名字

**情语** —— 有情绪的语音。

语音合成最容易做到"念对了"，最难做到"说得有情绪"。语气、轻重、停顿，都落在这个名字里。说话、朗读、唱歌都是"语"，共用一套引擎和风格，所以不分成三个名字。

谐音落在**琴语**——琴是弦上的东西，那是唱歌那一半。念起来一样，两种表达共用一个名字。

图标是那只笑着的手绘猫：它不唱歌也不朗诵，只是笑；但你在旁边说话、放歌，它都会听。
