# resources/ · 静态资源

图标源文件。只有一项，但单独放一个目录是有原因的。

## 内容

| 文件 | 用途 |
|---|---|
| `logo.svg` | 图标的矢量源文件（512×512） |

## 为什么图标有两个

```
logo.png   ← AstrBot 插件面板显示用，必须叫这个名字、必须在根目录
resources/logo.svg  ← 矢量源文件，可无损缩放，方便二次修改
```

AstrBot 只认根目录的 `logo.png`，所以 PNG 不能挪进来。但 PNG 是位图，改色改形状要重新导出；保留 SVG 源文件，下次想调颜色或笔画直接改这里、重新导出即可。

## 当前图标的来历

手绘风格的猫，白色圆角底，灰黑描边，右下角有个小卷尾。设计意图写在根目录 README 的「关于名字」一节：它不唱歌也不朗诵，只是笑——你在旁边说话、放歌，它都会听。

## 改图标

1. 改 `logo.svg`（或直接换一张图）
2. 导出 512×512 PNG，命名 `logo.png` 放**根目录**（不是这里）
3. 同时更新这里的 SVG，保持两份一致
4. 重新打包：`python tools/build_plugin_zip.py`

图标会显示在 AstrBot 的插件管理列表里，尺寸建议 512×512，圆角由 PNG 自带（AstrBot 不做二次裁切）。
